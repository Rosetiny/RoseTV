# 构建与分发

## 直接使用，不需要开发环境

完整仓库包含根目录 `RoseTV.exe`、`runtime/python-runtime.zip`、源码及经过校验的原生基底。下载 ZIP 并全部解压，或 Git 克隆后，双击根目录 `RoseTV.exe` 即可启动。无需安装 Python、Node.js、Rust，也无需自己运行构建命令。

第一次运行时，启动器校验运行环境 SHA-256，将其解压到 `runtime/python/`，再用随附 Python 执行 `tools/start.py`。脚本生成使用者自己的本机密钥，准备 `App/rosetv-native.exe` 后启动软件。后续启动校验资源指纹并复用已准备的文件；修改嵌入 JavaScript 时自动重新准备。

这些步骤在本地完成，不需要联网下载运行环境。影片资料和播放仍需要联网。Windows 10 / 11 x64 需具备 WebView2 Runtime；没有时从 Microsoft 官方安装。

## 修改源码

先启动一次软件，让运行环境自动解压。然后关闭软件，编辑源码，再双击根目录入口。`rosetv.js`、`rosetv.css` 通过本地服务读取；其他嵌入 JavaScript 由启动脚本根据指纹自动更新。

运行离线 Python 检查：

```powershell
.\runtime\python\python.exe -m unittest discover -s tools -p "test_*.py" -q
```

前端回归检查需要开发者另装 Node.js：

```powershell
node source/tests/performance.mjs
```

修改 C# 启动器后，使用 Windows .NET Framework C# 编译器重新生成入口：

```powershell
.\runtime\python\python.exe tools/build_local.py
Copy-Item build/RoseTV.exe RoseTV.exe -Force
```

`tools/build_local.py` 校验原生基底 SHA-256、嵌入资源内容、位置及压缩后长度，生成 `build/rosetv-native.exe` 和构建清单，并编译 C# 启动器。普通首次启动调用该脚本的资源准备函数，不需要 C# 编译器。原生机器代码保持原样；完整重编译 Rust / Tauri 需要相应工具链，与此流程不同。

## 重制运行环境

此项仅供维护者更新随附环境，不是使用者的启动步骤。需要完整 Python 安装及 pip：

```powershell
python -m pip install -r requirements.txt
python tools/package_runtime.py
python tools/build_local.py
Copy-Item build/RoseTV.exe RoseTV.exe -Force
```

打包脚本下载 Python 官方 Windows x64 嵌入式发行版并核验固定 SHA-256，从 PyPI 获取兼容的二进制依赖，生成压缩运行环境、SHA-256 文件和来源清单。Python 及依赖的许可证保留在环境包中。具体版本、下载来源和 wheel 哈希见 `runtime/manifest.json`。

环境版本更新时，建议把新版本解压到新目录，避免混用旧的已解压环境。正式运行不启用调试端口。

## 发给其他人

直接分享干净仓库的完整 ZIP，或仓库地址。对方全部解压后双击根目录 `RoseTV.exe`；代码也在同一包中，可以自行修改。

不要单独发送一个 EXE，不要把使用过的整个工作目录直接打包。排除 `tools/bridge-config.json`、`provider-session.bin`、浏览器档案、`runtime/python/`、`build/`、缓存、下载、观看记录和配置导出文件。`runtime/python-runtime.zip` 是公开运行依赖，需要保留。每个使用者首次启动生成自己的密钥和本机资料，不会复用开发者账号。

运行目录中的 `App/rosetv-native.exe` 含有当前安装生成的桥接配置，不提交到仓库。根目录 `RoseTV.exe` 是通用启动器，未嵌入开发者密钥。

`source/BUILDING.md` 指向本文。CI 使用随附 Python 执行离线检查和首次准备验证，不向影视网站施加压力。
