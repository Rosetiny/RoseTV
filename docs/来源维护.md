# 来源维护

当前来源定义在 `source/public/js/config.js`；红牛及用户来源整合在 `source/public/js/rosetv.js`。真实接口需要同时检查搜索、同片同年份匹配、详情、播放清单和首帧解码，不能只检查 HTTP 200。

## 2026-10-25 核验

- 量子：`https://cj.lziapi.com/api.php/provide/vod/`。已验证“生化危机”2002 的搜索、详情和真实首帧。具体测量见 `build/verified-replacement-sources.json`。
- 素博：`https://subocj.com/api.php/provide/vod/`。已验证“肖申克的救赎”1994 详情、HLS 清单及真实首帧。
- 金鹰：[官方接口说明](https://jinyingzy.com/help/) 提供 `https://jyzyapi.com/provide/vod/from/jinyingm3u8/at/json/`。搜索可用，但本机抽样视频未取得首帧，因此没有冒充可播放来源加入默认选择。
- 索尼：[官方帮助](https://suonizy.cc/help/) 的限定来源接口本轮未通过访问检查，没有改用其他路径绕过限制。

停用的天涯、卧龙、华为吧接口及原因留在 `retired-sources.json`，不再参与自动匹配和全量测试。其他来源的临时故障不通过猜测域名强行替换。

量子和素博另用电影、剧集、动漫、综艺、纪录片各一个常见样片实测，两个来源均 5/5 取得解码首帧。样片为“肖申克的救赎”“大明王朝1566”“千与千寻”“明星大侦探 第一季”“地球脉动 第一季”，不再为了测试向豆瓣请求五张评分榜。自动匹配优先查询实测评分更高的已选来源。

新接口以实际提供者名称加入，不把其他服务冒充成旧提供者。来源抽样成绩有时间戳，部分样片失败通常说明片库覆盖、线路或网络存在差异，不能推断整站全部不可用。

全量测试遇到明确不支持搜索、验证、停用或错误接口时，不继续对同一失败接口重复查询五种样片。网站地址发布页每天最多检查一次；发现新域名后仍要核验归属和登录域，禁止把 Cookie 发到未知域名。
