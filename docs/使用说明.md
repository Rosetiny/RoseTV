# RoseTV 使用说明

## 首次启动

从仓库下载完整 ZIP 并全部解压，或用 Git 克隆仓库，然后双击根目录 `RoseTV.exe`。运行环境已随项目提供，首次启动会自动解压并准备桌面文件，无需安装 Python 或手动构建。保留同一目录中的 `runtime/`、`source/`、`tools/`、`vendor/`；不要在 ZIP 内直接启动。后续继续使用根目录入口。

## 日常使用

- 首页展示近期热门内容。滚动到其他分类时自动加载，已缓存内容直接复用。
- 电影、剧集、动漫等分类支持类型、年份、地区、语言组合。上游没有提供的精确字段会说明限制。
- 点击海报播放；右上角星标可收藏。收藏、历史和设置保存在本机。
- 播放支持换源、线路、倍速、全屏和可缩放小窗。小窗返回时恢复原窗口位置和大小。
- 切换到教父来源后会重新读取该来源的下载资源；下载列表按需展开，不自动下载影片。

## 登录资料是什么

“网站登录浏览器资料”是用于完成网站正常登录与验证的独立浏览器档案，包含网站存储、Cookie 和浏览器自身数据。它与影片目录缓存不同，也不是下载的视频。会话通过 Windows 用户加密保存，不保存明文密码。

Chrome / Edge 类默认浏览器可用于专用登录窗口，其他默认浏览器使用 Edge 登录组件。不同域名的 Cookie 相互隔离，备用网址首次访问可能需要单独登录。

## 清理接口缓存

“清理接口缓存”删除前端接口内存缓存和后端目录快照，不删除收藏、观看记录、设置或加密登录会话。清理后首次访问片单需要重新请求，短时间内可能比缓存命中时慢。

该按钮不会删除网站登录浏览器档案或所有海报缓存。存储页面显示总磁盘占用和各项明细，不把内存缓存重复计入磁盘总量。

## 加载状态

- 空结果：当前上游索引没有匹配，或筛选组合未受支持；以页面具体提示为准。
- 本机访问预算等待：短时间请求较多，当前筛选会在倒计时后继续，旧缓存仍可访问。
- 网站验证或限流：停止新请求，遵守上游要求；不会通过换域名、换账号或自动重试绕过验证。
- 海报失败：显示重试入口；换页会取消旧页下载，避免旧图片占住连接。

新来源只代表实测样片可播放，不能保证全部影片、全部时段都可用。源测试需要网络，日常翻页不必重复测试全部来源。
